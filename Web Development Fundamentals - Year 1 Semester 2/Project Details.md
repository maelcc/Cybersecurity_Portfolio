# Project Details

## Purpose & Outcome

The purpose of this project was to build a simple, local, offline website from scratch using only HTML and CSS. The site is themed around The Witcher and includes a fake marketplace selling themed merchandise.

The site is a multi-page static website: a home page, character pages split into protagonists and antagonists, and pages for the books, the series, and the video games, plus a stories page, a summary page, a contact page, a site map, and the fictional merchandise page.

The outcome was a fully working website that opens directly in any browser with no server required, with consistent styling and navigation across every page.

## Technologies, Tools and Methods

- HTML5 for the structure of every page
- CSS for all styling, split into four modular stylesheets: main, body, header, and footer
- A screen design prepared before the build to plan the layout
- Multi-page site structure with a site map and cross-page navigation
- Fully offline, local deployment with no backend or server dependency
