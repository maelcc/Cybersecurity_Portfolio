# The Witcher Fan Website

A simple, fully offline website themed around The Witcher, including a fake marketplace selling themed merchandise. Built entirely with HTML and CSS, with no server or backend required.

## Pages

- `index.html` - home page
- `protagonists.html` and `antagonists.html` - character pages
- `books.html`, `series.html`, `videogames.html` - pages for the books, the series, and the games
- `stories.html` and `summary.html` - stories and overview content
- `merch.html` - the fake marketplace
- `contact.html` and `siteMap.html` - contact page and site map

## Structure

```
css/        Four stylesheets: main.css, body.css, header.css, footer.css
images/     Image assets used across the site
*.html      The site pages
```

## Usage

Open `index.html` in any browser. The site is fully static and works offline.

This project was created for educational purposes only. It is a coursework project published to demonstrate learning. The Witcher is a creation of Andrzej Sapkowski, and all related names and images belong to their respective owners. The marketplace is fictional and nothing is actually for sale.
